# 方法

## 問題

同一個個體貢獻多個樣本時，下面兩種常見做法會把測試準確率高估多少？

1. **以樣本為單位隨機切分**：同一個個體的樣本同時出現在訓練集與測試集。
2. **切分前先做前處理**：用全部樣本（含測試樣本）挑特徵、做標準化。

個案是 Basran et al. (2022)：他們用 50 匹純種賽馬、129 塊近端籽骨的 102 個 μCT 影像組學（radiomics）特徵訓練分類器。論文寫明 90／39 的骨頭切分與 10 折交叉驗證，但沒有說明同一匹馬的骨頭是否放在同一邊，也沒有說明挑特徵是否只用訓練資料。本專案不主張原論文有洩漏，而是在結構相同、答案已知的合成資料上，呈現每一種做法會讓數字變成多少。

## 樣本結構

依論文 p.3 與 Figure 1：

| | 馬 | 肢 | 骨 |
|---|---|---|---|
| 病例 | 30 | 30（各一肢） | 60（內側與外側） |
| 對照 | 20 | 35（15 匹雙肢、5 匹單肢） | 69（一塊外側骨影像損毀） |
| 合計 | 50 | 65 | 129 |

論文沒有寫損毀的骨頭屬於哪匹對照馬。主分析放在雙肢馬，E4 改放在單肢馬。

## 生成模型

第 *h* 匹馬、第 *l* 肢、第 *i* 塊骨的第 *j* 個特徵：

```
x_ij = a_hj + b_lj + e_ij + d · y_i · [j ≤ k]
a_hj ~ N(0, r·s),  b_lj ~ N(0, r·(1−s)),  e_ij ~ N(0, 1−r)
```

- 總變異數為 1。同一肢兩塊骨的相關為 *r*；同一匹馬不同肢的兩塊骨相關為 *r·s*。主分析 *r* = 0.7、*s* = 5/7，跨肢相關為 0.5。
- *d* 是真訊號，以標準差計，只加在 *p* = 102 個特徵的前 *k* = 5 個。*d* = 0 代表特徵與標籤無關，任何高於瞎猜的準確率都是假象。
- *r*、*s*、*d* 都是假設值，論文沒有報告同馬骨頭的相關；E2 與 E4 會改變它們。

## 流程

依論文 pp.4–6 與 Table 2：

1. 挑出前 *N* = 20 個特徵。論文用 100 棵樹的 out-of-bag 重要度排序；本專案為了速度改用 Welch *t* 統計量的絕對值。
2. 對挑出的特徵做 z 分數標準化。
3. 訓練六種分類器，參數對照 Table 2：無懲罰邏輯斯迴歸、二次 SVM、10 鄰居 KNN、Bagged Trees（30 棵）、RUSBoost（30 棵、21 葉、學習率 0.1）、單層 25 節點神經網路。另加 1-NN 作為極端示範，它只靠記住最近的鄰居。

第 1、2 步只用訓練列擬合（**乾淨**），或用全部 129 列擬合（**洩漏**）。

## 實驗

| 編號 | 變因 | 重複次數 | 產出 |
|---|---|---|---|
| E1 | 切分（骨／馬）× 前處理（乾淨／洩漏）× 7 個模型，*d* = 0 與 *d* = 1.0 | 500 | 主比較，圖 F1 |
| E2 | *r* ∈ {0, 0.3, 0.5, 0.7, 0.9}，*d* = 0；*r* = 0 是陰性對照 | 300 | 圖 F2 |
| E3 | *d* 從 0 到 1.5，*r* = 0.7 | 300 | 圖 F3 |
| E4 | 損毀骨放在單肢馬；以肢為主的相關（*s* = 0.3）；內外側骨系統差異 | 300 | 敏感度分析 |
| E5 | 10 折交叉驗證：以骨（`KFold`）vs 以馬（`GroupKFold`），前處理都在折內 | 200 | 交叉驗證版本 |
| E6 | 以馬分組 10 折交叉驗證，6 模型 × *N* ∈ {3, 5, 10, 20}：24 組平均 vs 最高的一組 | 200 | 挑最高分的樂觀偏差 |

每次重複都重新產生特徵並重新切分。彙總值有平均準確率、蒙地卡羅標準誤（標準差／√重複次數）、單次切分準確率的 2.5 與 97.5 百分位數、平衡準確率與 AUC。

*d* = 1.0 是為了讓以馬分組的準確率落在 0.70 左右，接近論文報告的範圍；這是示範用的校準，不是估計值。

### 洩漏率

90／39 隨機切分骨頭時，一塊來自擁有 *m* 塊骨之馬的測試骨，只有在同馬其他 *m* − 1 塊骨全部也在測試集時才不會洩漏：

```
P(洩漏) = 1 − C(38, m−1) / C(128, m−1)
```

129 塊骨平均為 0.826；`horsefold leak-rate` 會用 20,000 次模擬切分驗證。

## 限制

- 特徵是合成的。高估的幅度取決於 *r*，而真實骨頭的 *r* 未知。
- 挑特徵用 *t* 篩選取代論文的 out-of-bag 重要度，模型用 scikit-learn 取代 MATLAB Classification Learner；Table 2 有列出的超參數都設成一致。
- 只內建一種結構。其他結構可用 `Structure.from_groups` 建立，但 E1–E6 這組實驗是針對本個案設計的。
- 報告準確率是因為論文報告準確率。60 個病例對 69 個對照時，永遠猜多數類別的分類器平均得到 0.53；沒有訊號的分類器在以馬分組時可能低於 0.5，因為整匹馬移動會改變訓練集與測試集的類別比例。平衡準確率與 AUC 都在 JSON 裡。
